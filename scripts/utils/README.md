# Utility Scripts

This folder contains utility and helper scripts for various Validex operations.

## Current Status

This folder is currently empty but is reserved for future utility scripts such as:

- Database migration scripts
- Data import/export utilities
- System maintenance tools
- Development helper scripts
- Testing utilities

## Future Scripts

Planned utility scripts include:

- `migrate_database.py` - Database schema migration
- `export_data.py` - Export application data
- `import_data.py` - Import data from external sources
- `cleanup_temp.py` - Clean temporary files
- `validate_config.py` - Validate configuration files
- `backup_data.py` - Backup application data

## Usage

When utility scripts are added, they can be run directly:

```bash
# Example usage (when scripts are available)
python scripts/utils/migrate_database.py
python scripts/utils/export_data.py --format json
python scripts/utils/cleanup_temp.py --force
```
